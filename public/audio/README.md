# Audio files for Raging Sea reactivity

Place your `.mp3` or `.wav` file here (e.g. `music.mp3` or `intoSpace.mp3`).

Then in the Leva "Reactive Controls" panel:

1. Enable **Reactivity**
2. Set **Source** to **Audio File**
3. Set **Audio Path** to `/audio/yourfilename.mp3`
4. Click **▶ Play** to start (browsers require a user click before audio can play)
5. Adjust **Strength** to control how much the audio affects the waves
